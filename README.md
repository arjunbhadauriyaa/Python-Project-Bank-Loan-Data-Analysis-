# Data Analysis Performed 

In this project, Exploratory Data Analysis (EDA) was performed on the bank loan dataset to understand loan application patterns, customer behavior, and overall loan performance. The analysis started with data loading, data inspection, and cleaning to understand the structure, data types, and quality of the dataset. Various key performance indicators (KPIs) were calculated, including total loan applications, total funded loan amount, total amount received from customers, average interest rate, and average debt-to-income (DTI) ratio. The project further analyzed loan status to classify loans into Good Loans (fully paid and current loans) and Bad Loans (charged-off loans) to evaluate the bank's risk and profitability. Time-based analysis was performed to identify monthly trends in loan applications, funding, and repayments. The dataset was also analyzed based on different factors such as loan purpose, loan term, employee length, and geographical regions to find patterns in customer borrowing behavior. Data visualization techniques using Matplotlib and Seaborn were applied to create charts and graphs, making it easier to identify trends, compare categories, detect patterns, and generate meaningful business insights for decision-making.
